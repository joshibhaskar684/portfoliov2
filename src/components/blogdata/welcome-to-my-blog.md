Hi, I'm Bhaskar Joshi, a Software Engineer at Quana based in Haldwani, Uttarakhand.

I'm starting this blog to write down what I learn while building software, so I remember it better and so it might help someone working through the same problems.

## What I'll write about

- **Backend engineering** with Java, Spring Boot and NestJS
- **Cloud and DevOps**, including what I learned migrating a production database from Supabase to AWS RDS and moving an application from a VPS to AWS EC2
- **System design and distributed systems**: Kafka, Redis, microservices and the trade-offs between them
- **Frontend** work with React and Next.js
- **Agentic AI** experiments
